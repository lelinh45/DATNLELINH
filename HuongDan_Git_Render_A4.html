TRƯỜNG ĐẠI HỌC ĐIỆN LỰC — KHOA CÔNG NGHỆ THÔNG TIN

Hướng dẫn vận hành: đẩy code lên GitHub và xử lý lỗi Render

Hệ thống xác thực & chống giả mạo dữ liệu số bằng Blockchain — blockchain-data-integrity.onrender.com

I. Dùng hàng ngày

  • Chỉ cần mở link web blockchain-data-integrity.onrender.com — đăng nhập MetaMask, upload, xác thực, duyệt thiết bị đều làm trên giao diện.
  • Không cần mở VS Code hay chạy lệnh nào cho việc sử dụng thông thường.

II. Khi sửa code xong muốn đẩy lên web (Render tự deploy)

Mở terminal trong VS Code (Ctrl + `) rồi chạy lần lượt:

cd D:\NCKH26\Thu-muc-lon\blockchain-data-integrity

git status            # xem file nào đã sửa (chữ đỏ = chưa lưu)
git add -A            # gom hết thay đổi
git commit -m "ghi chú ngắn về thay đổi"
git push              # đẩy lên GitHub → Render tự build + deploy
  • Sau khi git push: chờ khoảng 1–3 phút, rồi bấm Ctrl + F5 trên trang web để tải bản mới (bỏ cache trình duyệt).
  • Trạng thái deploy xem tại render.com → Dashboard → project → Events: thấy "Deploy live" là xong.

III. Kiểm tra web có đang sống không

# Mong đợi kết quả: 200
curl -s -o /dev/null -w "%{http_code}" https://blockchain-data-integrity.onrender.com/
  • Xem server đang báo lỗi gì: Render → Dashboard → project → Logs (tìm dòng Error màu đỏ).

V. Redeploy thủ công khi cần (không sửa code)

  • Vào Render → Dashboard → project → Manual Deploy → Deploy latest commit.
  • Dùng khi: vừa sửa biến môi trường (SMTP...), hoặc build trước lỗi giữa chừng muốn chạy lại.
  • Biến môi trường sửa tại Render → project → Environment — sửa xong bắt buộc redeploy mới có hiệu lực.

VI. Lệnh hay dùng để xem lại

git log --oneline -5     # xem 5 commit gần nhất
git diff                 # xem chi tiết đang sửa những gì
Lưu ý quan trọng: không dùng git push -f (ép đẩy) và không xóa file .env (chứa khóa hệ thống). Nếu lỡ làm gì không chắc, chạy git status và chụp màn hình để hỏi trước khi tiếp tục.
